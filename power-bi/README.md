# Interactive Power BI Executive Dashboard
This folder contains the visualization layer of our end-to-end e-commerce data pipeline. The dashboard delivers interactive insights and advanced data modeling for business performance tracking.

* [PBI_SNOWFLAKE_PROJECT.pbix](./PBI_SNOWFLAKE_PROJECT.pbix) — Contains the complete Power BI Desktop file including data models, table relationships, and interactive dashboard sheets.

## Dashboard Highlights & DAX Measures
The visualization architecture focuses on structured data modeling and optimized query performance:

* *Data Modeling:* Built a clean Star Schema design connecting the Fact tables directly with Dimension tables to maximize performance.
* *Key Performance Indicators (KPIs):* Integrated dynamic cards monitoring critical metrics such as Total Sales, Active Customers, and Average Order Value (AOV).
