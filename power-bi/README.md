# Interactive Power BI Executive Dashboard
This folder contains the visualization layer of our end-to-end e-commerce data pipeline.

## Files Included- dashboard_visual.pbix: 
The complete Power BI Desktop file containing data models, relationships, and dashboard sheets.
- dashboard_screenshot.png: A high-quality image preview of the dashboard for quick evaluation within the browser.

## Dashboard Highlights & DAX Measures- Data Modeling: 
Built a clean Star Schema design connecting the Fact tables directly with Dimension tables.
- Key Performance Indicators (KPIs): Dynamic cards monitoring Total Sales, Active Customers, Average Order Value (AOV), and Order Fulfilment Rates.
- Advanced DAX: Authored custom DAX measures for Time Intelligence functions (e.g., Year-over-Year growth calculations, Moving Averages).
- User Experience: Integrated drill-down capabilities, interactive slicers (by Date, Category, Region), and tooltip page expansions.
